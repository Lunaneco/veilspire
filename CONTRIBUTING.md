# Contributing

Thank you for helping improve Veilspire.

## Before opening a change

1. Create a focused branch.
2. Install locked dependencies with `npm ci`.
3. Make the smallest change that solves the issue.
4. Run `npm run check`.
5. Confirm that no secrets, personal paths, save data, generated output, or
   machine-local settings are included.

## Pull requests

Describe the behavior before and after the change, how it was verified, and
any performance or accessibility impact. Screenshots are welcome for visual
changes, but remove personal information from images and metadata first.

By contributing, you agree that your contribution is licensed under the
repository's MIT License.

## Security reports

Do not open a public issue for a vulnerability. Follow
[SECURITY.md](SECURITY.md).
