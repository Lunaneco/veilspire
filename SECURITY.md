# Security Policy

## Supported version

Security fixes are applied to the latest revision of the `main` branch.

## Reporting a vulnerability

Please do not publish suspected vulnerabilities in a public issue.

Use the repository's **Security → Advisories → New draft security advisory**
page to report the issue privately. Include:

- the affected file or feature;
- steps to reproduce;
- the likely impact;
- a suggested fix, if available.

If private vulnerability reporting has not yet been enabled, the repository
owner should enable it under **Settings → Security → Private vulnerability
reporting** before accepting public contributions.

Do not include real credentials, access tokens, personal data, or exploit data
belonging to a third party in a report.

## Scope

Veilspire is a static client-side application with no backend. Browser save
data is stored locally. Reports about injected third-party builds, modified
copies, browser extensions, or unsupported browsers may be outside the
project's control.
